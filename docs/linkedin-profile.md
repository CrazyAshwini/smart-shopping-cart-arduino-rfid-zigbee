**Project Name:** Smart Shopping Cart using Arduino RFID and Zigbee

**Associated Skills:** Arduino, Embedded Systems, RFID, Zigbee, IoT, C/C++, Serial Communication, Hardware Prototyping, Retail Automation

**Project Description:**

Developed a smart shopping cart using Arduino, RFID, and Zigbee to automate product identification and billing in retail stores. The system scans RFID-tagged products, displays item details and the total bill on an LCD, and transmits the final billing data wirelessly to the server side using Zigbee communication.

This project helped me gain practical experience in embedded systems, RFID integration, wireless communication, LCD interfacing, serial communication, and hardware prototyping.
