# Circuit Diagram

Add your circuit diagram, Proteus schematic, or hardware connection photo in the `images/` folder and link it here.

Suggested files:

- `images/circuit-diagram.png`
- `images/proteus-simulation.png`
- `images/hardware-setup.jpg`

## Suggested Connections

| Module | Arduino Pin |
| --- | --- |
| LCD RS | 8 |
| LCD EN | 9 |
| LCD D4 | 10 |
| LCD D5 | 11 |
| LCD D6 | 12 |
| LCD D7 | 13 |
| Checkout Switch | 5 |
| Buzzer | 7 |
| RFID Reader TX | Arduino RX or configured serial input |
| Zigbee TX/RX | Serial communication pins, depending on module setup |

Check the exact pin mapping with your final hardware circuit before uploading the firmware.
