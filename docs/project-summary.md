# Project Summary

## Title

Smart Shopping Cart using Arduino RFID and Zigbee

## Category

IoT, Embedded Systems, RFID Based Billing, Zigbee Wireless Communication, Retail Automation

## Overview

This project implements a smart shopping trolley that reduces checkout waiting time in supermarkets. RFID cards or tags are used to identify products. When a product is scanned, the Arduino updates the item count and total amount and displays the information on a 16x2 LCD. At checkout, the final bill is transmitted wirelessly to the server side using Zigbee.

## Objective

The objective is to create a low-cost shopping trolley prototype that supports automatic billing, improves shopping speed, reduces manual scanning, and helps customers monitor the total bill while shopping.

## Main Modules

- RFID reader for product identification
- Arduino for billing logic and display control
- LCD for item and bill display
- Zigbee module for wireless billing transmission
- Buzzer for scan feedback
- Checkout switch for final bill confirmation

## Outcome

The prototype demonstrates that RFID and Zigbee can be combined to create a faster shopping and billing system. It can help reduce queues, minimize manual billing errors, and improve the customer shopping experience.
